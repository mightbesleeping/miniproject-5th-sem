About Endpoint Threat Detection (EDR) Engine

This application is a modular, real-time Endpoint Detection and Response (EDR) tool built to monitor system activities, parse Linux kernel audit logs, evaluate threat detection rules, and provide interactive analytics via a high-performance database.

Core Architecture & Key Concepts

  • Linux Audit Framework (auditd): Hooks directly into the Linux kernel auditing subsystem to capture system calls, process executions, and file accesses in real time.
  • YAML Threat Rules: Modular detection signatures mapped against ATT&CK matrices covering reverse shells, privilege escalation, and persistence techniques.
  • Columnar Analytics (DuckDB): All alerts are stored locally in an optimized columnar database supporting fast aggregations, time-series bucketing, and session correlation.
  • MITRE ATT&CK Framework (Learn More): A globally accessible knowledge base of adversary tactics and techniques used to categorize threat behaviors.

Project Utility

Designed for academic and enterprise threat analysis, this dashboard enables security analysts or students to review historic attacks, simulate log replays, and instantly identify malicious behavior like /dev/tcp reverse shells or LD_PRELOAD injection attempts without risking live environments.
